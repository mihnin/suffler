# Суфлёр — телесуфлёр для съёмки видео

Автономное веб‑приложение для iPad (в первую очередь iPad 13" в горизонтальной ориентации).
Без аккаунтов, без серверов, без рекламы. Сценарии хранятся **только на вашем устройстве**.

**Адрес приложения: https://mihnin.github.io/suffler/** — откройте его в Safari на iPad и добавьте на экран «Домой» (раздел 3).

---

## Что внутри папки

| Файл | Зачем |
|---|---|
| `index.html`, `style.css`, `app.js` | само приложение |
| `manifest.json`, `service-worker.js`, `icons/` | установка на экран «Домой» и работа без интернета |
| `Запустить суфлёр.bat` | запуск на Windows двойным щелчком |
| `Запустить суфлёр.command` | запуск на Mac двойным щелчком |
| `start_server.py` | маленький веб‑сервер, который запускают файлы выше |

## 1. Как запустить на компьютере

1. Нужен Python (на Mac он уже есть; на Windows — скачайте с python.org и при установке поставьте галочку **Add Python to PATH**).
2. Дважды щёлкните **`Запустить суфлёр.bat`** (Windows) или **`Запустить суфлёр.command`** (Mac).
3. Откроется браузер с приложением. Окно с чёрным фоном не закрывайте, пока пользуетесь.

> Можно и просто открыть `index.html` двойным щелчком — чтение и прокрутка будут работать, но без офлайн‑режима и голосовых функций.

---

## 2. Как открыть на iPad

Есть два способа. **Для съёмок рекомендую способ Б** — только он даёт полноценную работу без интернета и доступ к микрофону.

### Способ А — быстро попробовать (тот же Wi‑Fi)
1. Запустите суфлёр на компьютере (раздел 1).
2. В окне сервера будет строка вида `С iPad (та же Wi-Fi): http://192.168.1.23:8000`.
3. Откройте этот адрес в Safari на iPad.

Ограничение: по адресу `http://192.168…` Safari **не разрешает** офлайн‑режим и микрофон (это требование безопасности браузера — нужен HTTPS). Чтение, прокрутка, зеркало, настройки — работают.

### Способ Б — постоянный адрес с HTTPS (бесплатно, один раз)
Приложение — это просто набор файлов. Их нужно положить на любой бесплатный хостинг с HTTPS. Ваши тексты при этом **никуда не загружаются** — на хостинге лежит только «пустое» приложение, сценарии остаются в памяти iPad.

**GitHub Pages (бесплатно, навсегда):**
1. Зарегистрируйтесь на github.com.
2. Нажмите **New repository** → имя, например, `suffler` → **Public** → **Create repository**.
3. Нажмите ссылку **uploading an existing file** и перетащите **все файлы и папку `icons`** из этой папки → **Commit changes**.
4. Откройте **Settings → Pages** → в «Branch» выберите `main` и `/ (root)` → **Save**.
5. Через 1–2 минуты приложение будет доступно по адресу `https://ВАШ-ЛОГИН.github.io/suffler/`.

**Netlify (альтернатива):** зарегистрируйтесь на netlify.com, откройте **app.netlify.com/drop** и перетащите туда папку `teleprompter` целиком. Netlify выдаст адрес `https://….netlify.app`.

Откройте полученный `https://…` адрес в Safari на iPad.

## 3. Как добавить на экран «Домой» (как обычное приложение)

1. Откройте `https://…` адрес в **Safari** на iPad.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выберите **«На экран "Домой"»** → **«Добавить»**.
4. На экране появится иконка **«Суфлёр»**. Запускайте приложение с неё — оно откроется во весь экран, без адресной строки.

---

## 4. Как пользоваться без интернета

1. **Один раз** откройте приложение с интернетом (способ Б) и подождите 5–10 секунд — оно сохранится на iPad.
2. Проверить: **Настройки → Данные, офлайн и сброс** — там должно быть написано «Офлайн‑режим готов».
3. Дальше можно включать «Авиарежим»: приложение и все сценарии работают.

Не работает без интернета только **Voice Follow** (распознаванию речи Apple нужен интернет). **Voice Pause** работает офлайн.

**Важно про сохранность текстов:** Safari может удалить данные сайта, который не открывали больше 7 дней. Приложение, добавленное на экран «Домой», так не очищается. Всё равно время от времени делайте **Настройки → Резервная копия всех сценариев** (сохраняется в «Файлы»).

## 5. Как пользоваться

### Сценарий
- Вставьте текст (кнопка **«Вставить из буфера»** или обычная вставка) — он **сохраняется автоматически** при каждом изменении.
- Пустая строка — новый абзац.
- Режиссёрские пометки пишите в квадратных скобках: `[ПАУЗА]`, `[УЛЫБКА]`, `[СМЕХ]`, `[ТИШЕ]`, `[ГРОМЧЕ]`, `[СМОТРИТ В СТОРОНУ]`… Они видны в суфлёре цветной плашкой, не считаются словами и не мешают Voice Follow. Кнопки‑маркеры над текстом вставляют их в место курсора.
- Внизу — **ориентировочная длительность** при указанном темпе речи (слов в минуту).
- Слева список сценариев: новый, переименовать, дублировать, удалить (с кнопкой «Вернуть»), Импорт TXT / Экспорт TXT.

### Чтение
- **«Начать»** — открывается суфлёр, идёт обратный отсчёт 3‑2‑1, текст поехал.
- **Одно касание по тексту** — пауза / продолжить. Панель управления сама прячется через 3 секунды.
- **Провести пальцем вверх/вниз** — подвинуть текст вручную.
- Кнопки: Сначала · Стоп · ↶ 5 сек · −3 строки · −1 строка · Пауза/Старт · +1 строка · Медленнее/Быстрее и ползунок скорости.
- **Скорость** 0–100: одна единица ≈ 4 слова в минуту (35 ≈ 140 сл/мин). Скорость **не меняется**, если вы меняете шрифт или ширину колонки.
- Если Safari закрылся — при следующем запуске суфлёр откроется на том же месте.

### Чтобы взгляд не «бегал»
- **Настройки → Пресеты → Camera Eye Contact**: узкая колонка, крупный текст, ярко видны только 2 строки, остальное приглушено.
- **Зона чтения**: подвиньте её как можно ближе к объективу iPhone. Если iPhone стоит над iPad — зону ставьте выше (20–30 % от верха).
- Чем дальше iPad от лица и чем ближе зона к камере — тем меньше заметно движение глаз. Узкая колонка (30–45 %) почти убирает движение глаз по горизонтали.
- Ширина колонки считается от длинной стороны экрана, поэтому при повороте iPad физическая ширина строки не меняется.

## 6. Зеркальный режим (Mirror Mode)

Для настоящего суфлёра с полупрозрачным стеклом:
- Кнопка **«Зеркало»** в верхней панели или клавиша **M** — отражение по горизонтали.
- **Настройки → Зеркало**: *Mirror Horizontal* и *Mirror Vertical* (для конструкций, где iPad лежит «вверх ногами»).
- Отражается только текст, кнопки управления остаются читаемыми.
- Пресет **«Стеклянный суфлёр»** включает зеркало и крупный жирный текст.

## 7. Голосовые режимы

**Настройки → Голос → Режим**:

### Voice Pause (рекомендую для съёмок)
Пока вы говорите — текст едет с выбранной скоростью. Замолчали — он плавно останавливается. Продолжили — плавно поехал дальше.
- Звук анализируется **только на iPad**, никуда не отправляется. Работает без интернета.
- **Чувствительность** и **«Остановка после тишины»** настраиваются. Нажмите **«Проверить микрофон»**: при обычной речи зелёная полоса должна заходить за жёлтую метку, в тишине — нет.
- Нужен адрес `https://…` (способ Б) — по `http://192.168…` Safari не даёт доступ к микрофону.

### Voice Follow (экспериментально)
Суфлёр распознаёт вашу речь, находит сказанное в тексте и держит нужную строку в зоне чтения. Замолчали — текст стоит. Ошибки, пропущенные слова, другие окончания, повторы и импровизация допускаются (используется нечёткое сравнение слов). Если вернулись назад и повторили фразу — текст тоже вернётся.
- Перед включением приложение предупредит: **в Safari распознавание выполняет служба Apple (Siri/Диктовка), и звук может отправляться на серверы Apple.** Текст сценария не отправляется.
- Кнопка **«Проверить распознавание»** показывает, что реально слышит браузер.
- Если распознавание недоступно или прервалось — приложение **сообщит об этом и включит обычную прокрутку**. Оно не делает вид, что работает.

### Ограничения Voice Follow в Safari / iPadOS
- Нужен интернет, включённые **Siri** и **Диктовка** (Настройки iPad → Основные → Клавиатура → Включение диктовки) и HTTPS‑адрес.
- В режиме приложения с экрана «Домой» iPadOS на ряде версий **запрещает** распознавание речи. Если видите «Voice Follow недоступен» — откройте тот же адрес в обычном Safari.
- Safari периодически сам останавливает распознавание (после паузы или примерно через минуту). Приложение автоматически перезапускает его; если это происходит слишком часто — переходит на обычную прокрутку.
- Задержка распознавания около 0,5–1 секунды: текст догоняет речь с небольшим опозданием. Поэтому держите 2–3 строки в зоне чтения.
- Числа («2024» в тексте против «две тысячи двадцать четыре» в речи) сопоставляются плохо — такие места суфлёр просто «перешагнёт» по следующим словам.
- Микрофон iPad слышит и других людей в комнате — для Voice Follow лучше, если говорит только один человек.

Если Voice Follow ведёт себя нестабильно — используйте **Voice Pause**: он полностью локальный и предсказуемый.

## 8. Клавиатура и Bluetooth‑пульт

Подойдёт любая Bluetooth‑клавиатура или пульт, который работает **как клавиатура** (большинство презентационных кликеров и пультов для суфлёров). Подключите его в **Настройки iPad → Bluetooth**.

| Клавиша | Действие |
|---|---|
| Пробел, Enter, PageDown | Пауза / продолжить |
| ↑ / ↓ | Быстрее / медленнее |
| ← / → | Немного назад / вперёд (1–3 строки, настраивается) |
| PageUp, B | Назад на 5 секунд |
| Home / End | В начало / в конец текста |
| R | Сначала (с отсчётом) |
| S | Стоп |
| M | Зеркало |
| T | Время и прогресс |
| Esc | Выход из режима чтения |

У типичного кликера две кнопки: «вперёд» (PageDown) = пауза/продолжить, «назад» (PageUp) = вернуться на 5 секунд.

**Свой пульт:** Настройки → Клавиатура и Bluetooth‑пульт → нажмите **«Назначить»** напротив действия и нажмите кнопку на пульте. Приложение не привязано к конкретной модели.

> Кнопки громкости и мультимедиа (▶︎❚❚) Safari в веб‑приложения не передаёт — такие пульты нужно переключить в режим клавиатуры (у многих есть переключатель режимов).

## 9. Советы для съёмки

- Перед дублем: **Настройки iPad → Экран и яркость → Автоблокировка → Никогда** (приложение тоже просит экран не гаснуть, но так надёжнее).
- Включите режим «Не беспокоить», чтобы уведомления не всплывали поверх текста.
- Яркость iPad — на максимум, особенно со стеклянным суфлёром.
- Время, прошедшее и оставшееся, и процент — кнопка **«Время»** (или клавиша T); в основном режиме не показываются.

---

## 10. Приватность

- Сценарии, настройки и позиции чтения хранятся только в памяти браузера на этом устройстве (localStorage).
- Приложение не делает никаких сетевых запросов, кроме загрузки собственных файлов.
- Исключение — Voice Follow: системное распознавание речи браузера (Apple или Google) может передавать звук на свои серверы. Об этом показывается предупреждение перед включением.
